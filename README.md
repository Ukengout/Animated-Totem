# Animated-Totem
Это сайт-конструктор для создания ресурспака на анимированный 2D тотем с уникальным скином и настраиваемой анимацией. Ресурспаки работают на всех версиях игры кроме 1.12.2 и ниже, включая самые последние. Благодаря системе imd, добавленной в 1.21.4, ресурспаки сделанные на этом сайте будут работать без optifine. Ниже версии 1.21.4 optifine нужен!!! Настройте свою анимацю, загрузите свой скин, настройте ресурспак по своему!!!!! Почувствуйте себя майншилдовцом с анимированным тотемом в руке!!! Чтобы тотем изменил текстуру нужно ввести имя, заданное на сайте, остальные тотемы останутся неизменными!!! Это первый сайт дающий возможность создавать в пару кликов очень красивые ресурспаки как у ютуберов!!! Анимации могут быть любыми от кувырков, прышком, махов руками, поправления очков до полного превращения в другого игрока, лазера из глаз, полёта и тд.
